    Hugo 入门：从零搭建一个 AI 友好的静态博客

    为什么选 Hugo？ Hugo 是目前最轻量、构建速度最快的静态站点生成器之一。一个中等规模的博客（几百篇文章），Hugo 可以在几百毫秒内完成构建，对比 Jekyll（几秒）、Next.js（几十秒到几分钟），优势非常明显。 结合 PaperMod 主题和 Cloudflare Pages 的免费全球 CDN 部署方案，你可以在 10 分钟内上线一个自己的博客。 本文目标 读完本文，你将获得： ✅ 完整的项目源码（Hugo + PaperMod） ✅ 开箱即用的 config.yml 配置 ✅ 面向 AI 大模型的 JSON-LD 结构化数据、llms.txt、robots.txt ✅ Cloudflare Pages 一键部署参数 ✅ 完整的 Markdown 发文工作流 目录结构约定（Hugo Page Bundle） Hugo 推荐使用 Page Bundle（页面包） 模式管理文章。每篇文章是一个独立文件夹，Markdown 和配图放在一起： content/posts/ ├── my-first-article/ │ ├── index.md # 文章正文 │ ├── cover.svg # 封面图（小驼峰命名） │ └── diagram.png # 正文配图 └── another-article/ ├── index.md └── images/ ├── screenshot-1.jpg └── screenshot-2.jpg ...
